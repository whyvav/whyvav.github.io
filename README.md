# whyvav.github.io

Personal academic website of **Vaibhav Shukla** — astrophysicist and data scientist.

**Live site:** https://whyvav.github.io

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template (itself a fork of the [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) theme). Hosted via GitHub Pages — pushing to `main` triggers an automatic build and deploy.

---

## Running locally

Ruby 3.3 + DevKit installed at `C:\Ruby33-x64\` (Windows native).

```powershell
bundle exec jekyll serve -l -H localhost
```

Site available at http://localhost:4000. Markdown/HTML changes hot-reload automatically; `_config.yml` changes require a server restart.

See [CLAUDE.md](CLAUDE.md) for a full description of the site architecture, content structure, and current state.
